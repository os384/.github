# .github (org-profile)

This repo holds the GitHub organization profile for
[github.com/os384](https://github.com/os384) — the actual landing-page content
is [profile/README.md](profile/README.md), which GitHub renders on the
organization page. Logo assets live in `profile/`.

Within the [os384 superproject](https://github.com/os384/os384) this repo is
checked out as the `org-profile/` submodule.
